This is a custom LLM harness that employs models from ollama, giving them the capacity to execute tools inside of your machine.  
The current tools include:  
-Reading files.  
-Writing files.  
-Editing files.  
-Listing directories.  
-Finding files.  
-Finding patterns in text.  
-Changing the working directory.  
-Running shell commands.  
-Running python commands.  
-Running commands in a new terminal (kitty by default).  
-Writing to a memory file ~/.agent/memory.md.  
-Reading the memory file.
